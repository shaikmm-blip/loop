# loop

**Never lose a connection again.** Loop keeps college students from losing the people they coffee chat with.

- Paste coffee chat notes → AI profile, personalized thank-you, 90-day follow-up plan
- Dashboard with warm / cooling / cold tracking and a daily follow-up queue
- Contact profiles with news activity → follow-ups that reference both the news and your original chat
- Premium Network Map with warm-intro path finding

Built at the FSB AI Build-a-thon. Next.js 15, Tailwind 4, framer-motion, react-force-graph-2d.

Set `ANTHROPIC_API_KEY` to use Claude; without it, Loop's built-in generator is used so the demo never breaks.
